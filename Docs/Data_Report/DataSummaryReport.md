## Relationship between explanatory variables and target variable
	The best relationship between the explanatory variables and the target variable LN_IC50 comes from drug-related features, in specific the encoded drug variable and the TARGET_PATHWAY, which help capture the differences in drug behavior and mechanisms. Cancer type variables such as TCGA_DESC and tissue descriptors show a moderate relationship, this helps explain variation across different cancer groups. The target variable is primarily influenced by drug-related features, with cancer type and genomic variables providing additional context that improve predictive performance.
